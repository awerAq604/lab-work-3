Вариант 8. Кафе
Задание 1. Ввести n (1..20) — число позиций меню. С помощью for вывести цены позиций по формуле 2.5 + i*0.5 и найти сумму цен всех позиций.
Задание 2. С помощью while вводить стоимость очередного заказа до ввода 0. Отрицательные значения пропускать. Посчитать общую выручку и число заказов дороже 30.
Задание 3. Через do-while запросить количество персон от 1 до 12. После корректного ввода вывести минимальное количество столов по 4 места, используя простую арифметику и остаток от деления.
Задание 4. Ввести rows и cols (1..8). Вложенными for вывести схему столиков: на главной диагонали печатать X, в остальных ячейках — точку.
